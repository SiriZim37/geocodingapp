# GeocodingApp

## Overview

**GeocodingApp** is a concept Android application designed to support a location-based work assignment and completion system. It helps employees receive, navigate to, and complete physical tasks — such as visiting customers to sign contracts — using GPS, geolocation services, and file-based documentation.

The app integrates Google Maps Platform to improve user experience and includes functionality for file handling and QR code scanning to complete tasks reliably and efficiently.

## Features

- 📍 Display physical task locations using **Google Maps**
- 🧭 Address resolution with **Geocoder API**
- 🏠 Visual navigation using **Street View**
- 📡 Real-time GPS location tracking
- 📁 Upload and display documents and image files
- 🖼️ Support for attaching and viewing photos related to the task
- 🔄 QR code scanning for secure task verification or completion
- 🗺️ Map-based task overview with interactive UI

## Getting Started

1. Clone the repository  
2. Add your **Google Maps API key** in `local.properties` or inside the `AndroidManifest.xml`  
3. Ensure you have enabled the following APIs in [Google Cloud Console](https://console.cloud.google.com):
   - Maps SDK
   - Geocoding API
   - Street View API
4. Build the app using Android Studio
